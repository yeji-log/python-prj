# 파이썬 개념 테스트

PRO_PLAN.md 기반으로 만든 MVP입니다. 동아리 학생이 수업 자료(노션/코랩 텍스트)를 붙여넣으면
파이썬 개념 목록을 뽑아주고, 개념별로 학습 → 난이도(상/중/하) 선택 → 코드 문제 테스트 → 결과/오답 리뷰까지
진행할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속.

## 화면 흐름

1. `/` — 자료 붙여넣기 → "개념 생성하기"
2. `/concepts` — 추출된 개념 목록에서 하나 선택
3. `/concepts/[id]` — 개념 설명 학습 → "테스트 시작"
4. `/concepts/[id]/difficulty` — 난이도(상/중/하) 선택
5. `/concepts/[id]/test?level=...` — 문제 풀이 → 결과 → 오답 리뷰 (한 화면 안에서 단계 전환)

## 개념 추출 방식

`src/lib/conceptData.ts` 에 미리 정의한 6개 개념(변수와 자료형 / 조건문 / 반복문 / 리스트 / 딕셔너리 / 함수)의
키워드가 붙여넣은 텍스트에 있는지로 판단합니다. 매칭되면 근처 문단을 설명으로 사용하고,
못 찾으면 기본 설명을 보여줍니다. 실제 서비스에서는 이 부분을 LLM 기반 추출로 교체할 수 있습니다
(`src/lib/extractConcepts.ts`).

## 상태 저장

- 생성된 개념 목록: `sessionStorage` (새로고침해도 유지, 탭을 닫으면 사라짐)
- 진행 중인 테스트 답안: 저장하지 않음 — 새로고침/뒤로가기 시 항상 새 문제로 다시 시작되고,
  안내 배너로 이전 진행 상황이 사라졌음을 알려줍니다. (`src/app/concepts/[id]/test/page.tsx`)

## 배포

`next.js + firebase + vercel` 스택으로 계획되어 있습니다. 현재 MVP는 서버/DB 없이 클라이언트 상태만으로 동작하므로,
Vercel에 그대로 배포할 수 있습니다. Firebase(인증/저장)는 다음 단계(P1: 계정별 기록 저장 등)에서 연결하면 됩니다.
